# Deluxe-Phisher
Technische Dokumentation zu URL-Maskierung, Reverse-Proxys mit Nginx, DNS- und SSL-Konfigurationen sowie Zugriffssteuerung für Webanwendungen. Behandelt Weiterleitungsmechanismen, Subdomain-Verwaltung, Caching und Traffic-Filterung zu Analyse-, Forschungs- und Infrastrukturzwecken.
